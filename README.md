# Customer Behavior Analysis Dashboard

## Project Overview
The Customer Behavior Analysis Dashboard is a data analytics project developed using Python, Pandas, SQL, and Power BI to analyze customer purchasing patterns, transaction data, and sales trends. The project transforms raw transaction data into meaningful insights through data cleaning, exploratory data analysis, SQL queries, and interactive visualizations.

## Objectives
- Analyze customer purchasing behavior and transaction patterns.
- Identify sales trends and purchasing insights.
- Clean and preprocess data to improve data quality.
- Use SQL to retrieve, filter, group, and analyze data.
- Build an interactive Power BI dashboard for data-driven decision-making.

## Tools and Technologies
- **Python:** Data analysis and preprocessing.
- **Pandas:** Data cleaning and manipulation.
- **SQL:** Data querying and analysis.
- **Power BI:** Interactive dashboard development and visualization.

## Project Workflow
1. **Data Preparation:** Imported and inspected customer transaction data.
2. **Data Cleaning:** Used Python and Pandas to handle data quality issues and prepare the dataset.
3. **Exploratory Data Analysis:** Examined purchasing patterns, customer behavior, and sales trends.
4. **SQL Analysis:** Used SQL queries to filter, group, and summarize transaction data.
5. **Dashboard Development:** Created interactive Power BI visualizations to present key metrics and insights.

## Dashboard
The Power BI dashboard presents customer transaction analysis and purchasing trends through interactive visualizations.

To explore the dashboard, download the `.pbix` file from this repository and open it using Power BI Desktop.
